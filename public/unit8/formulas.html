Chapter 8 — Key Formulas

Statistics & Probability · Class 10 Samacheer Kalvi

Mean (Grouped Data)

Direct Method
x̄ = Σfx / Σf
x = midpoint of class, f = frequency of class
Assumed Mean Method
x̄ = A + (Σfd / Σf) where d = x − A
A = assumed mean (any convenient class midpoint)
Step Deviation Method
x̄ = A + (Σfu / Σf) × h where u = (x − A) / h
h = class width; reduces large numbers in calculation

Median (Grouped Data)

Median Formula
Median = L + [(n/2 − cf) / f] × h
L = lower class boundary of median class
n = Σf = total frequency
cf = cumulative frequency of all classes before median class
f = frequency of median class
h = class width
Median class = class containing the (n/2)th value (use cumulative frequency table)

Mode (Grouped Data)

Mode Formula
Mode = L + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h
L = lower boundary of modal class (class with highest frequency)
f₁ = frequency of modal class
f₀ = frequency of the class before modal class
f₂ = frequency of the class after modal class
h = class width

Standard Deviation & Variance

Variance (ungrouped)
σ² = Σ(x − x̄)² / n
Variance (grouped)
σ² = Σf(x − x̄)² / Σf
Standard Deviation
σ = √(σ²) Shortcut: σ = √[Σfx²/Σf − (Σfx/Σf)²]
SD is always ≥ 0. If SD = 0, all data values are equal.

Probability

Classical Probability
P(A) = n(A) / n(S)
n(A) = favourable outcomes, n(S) = total outcomes in sample space
Complementary Events
P(A') = 1 − P(A) P(A) + P(A') = 1
A' = complement of A (event A does NOT occur)
Addition Theorem
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
If A and B are mutually exclusive (cannot both occur): P(A ∩ B) = 0
∴ P(A ∪ B) = P(A) + P(B)
Key Sample Spaces
One die: n(S) = 6 One coin: n(S) = 2 Two coins: n(S) = 4 Two dice: n(S) = 36 Deck of cards: n(S) = 52
Deck: 4 suits × 13 cards each · 26 red (hearts + diamonds) · 26 black (spades + clubs) · 4 aces, 4 kings, 4 queens, 4 jacks
