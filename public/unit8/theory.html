1. Measures of Central Tendency

Mean

Direct Method: x̄ = Σfx / Σf (for grouped data with midpoints x)

Assumed Mean Method: x̄ = A + (Σfdₐ / Σf), where dₐ = x − A

Step Deviation Method: x̄ = A + (Σfuₐ / Σf) × h, where uₐ = (x − A)/h

Median (for grouped data)

Median Formula

Median = L + [(n/2 − cf) / f] × h

L = lower class boundary of median class
n = total frequency (Σf)
cf = cumulative frequency before median class
f = frequency of median class
h = class width

Mode (for grouped data)

Mode Formula

Mode = L + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h

L = lower boundary of modal class (class with highest frequency)
f₁ = frequency of modal class
f₀ = frequency of class before modal class
f₂ = frequency of class after modal class
h = class width

2. Measures of Dispersion

Dispersion measures how spread out the data is.

  • Range: Maximum value − Minimum value
  • Mean Deviation: Average of |x − x̄| for all values
Variance (σ²)

For ungrouped data: σ² = Σ(x − x̄)² / n
For grouped data: σ² = Σf(x − x̄)² / Σf

Standard Deviation (σ)

σ = √(Variance) = √[Σf(x − x̄)² / Σf]

Shortcut: σ = √[Σfx² / Σf − (Σfx/Σf)²]

Standard deviation is always ≥ 0. SD = 0 means all values are the same.

3. Probability

Probability Definition

P(A) = n(A) / n(S)

n(A) = number of favourable outcomes for event A
n(S) = total number of outcomes in sample space S

Key Properties

  • 0 ≤ P(A) ≤ 1 for any event A
  • P(S) = 1 (certain event)
  • P(∅) = 0 (impossible event)
  • Complementary events: P(A) + P(A') = 1
Addition Theorem

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
If A and B are mutually exclusive (A ∩ B = ∅):
P(A ∪ B) = P(A) + P(B)

Common Sample Spaces

  • One die: S = {1,2,3,4,5,6}, n(S) = 6
  • Two coins: S = {HH, HT, TH, TT}, n(S) = 4
  • Deck of cards: n(S) = 52 (13 each of 4 suits; 26 red, 26 black)
