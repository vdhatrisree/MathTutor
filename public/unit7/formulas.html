Chapter 7 — Key Formulas

All mensuration formulas · Class 10 Samacheer Kalvi · Use π = 22/7

Cylinder

Cylinder — r = radius, h = height
CSA = 2πrh TSA = 2πr(r + h) Volume = πr²h

Cone

Cone — r = base radius, h = height, l = slant height
Slant height: l = √(r² + h²) CSA = πrl TSA = πr(r + l) Volume = (1/3)πr²h
Remember: Volume of cone = (1/3) × Volume of cylinder with same r and h

Sphere

Sphere — r = radius
Surface Area = 4πr² Volume = (4/3)πr³

Hemisphere

Hemisphere — r = radius
CSA (curved only) = 2πr² TSA (curved + flat base) = 3πr² Volume = (2/3)πr³
Volume of hemisphere = (1/2) × Volume of sphere

Frustum (Truncated Cone)

Frustum — R = bottom radius, r = top radius, h = height
Slant height: l = √(h² + (R − r)²) CSA = π(R + r)l TSA = π(R + r)l + πR² + πr² Volume = (πh/3)(R² + r² + Rr)

Volume Conservation

When a solid is melted and recast
Volume (original) = Volume (new shape)
The total volume does not change. Use this to find unknown dimensions of the new shape.
Number of small spheres from big sphere
n = (R/r)³
n = number of small spheres of radius r formed from big sphere of radius R.
