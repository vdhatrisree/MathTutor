Chapter 1 — Relations & Functions

1. Sets — Quick Recap

A set is a well-defined collection of distinct objects. Sets are denoted by capital letters A, B, C…

Cartesian Product

For sets A and B, A × B = {(a, b) | a ∈ A and b ∈ B}. The number of elements in A × B = n(A) × n(B).

Example
A = {1, 2}, B = {a, b} → A × B = {(1,a), (1,b), (2,a), (2,b)}

2. Relations

Relation

A relation R from set A to set B is any subset of A × B. If (a, b) ∈ R, we write a R b.

Key Terms

TermMeaning
DomainSet of all first elements (x-values) in R
Co-domainSet B (all possible second values)
RangeSet of all second elements actually used in R (Range ⊆ Co-domain)
A relation is simply a rule that pairs elements of A with elements of B. Not every element of A needs to be paired, and an element can have multiple images.

3. Functions

Function (Definition)

A relation f: A → B is a function if every element of A has exactly one image in B.

Conditions for a function:

  • Every element in A must be mapped.
  • Each element in A maps to exactly one element in B (no splitting).
  • Different elements in A may map to the same element in B.
Not a function
If 1 → a AND 1 → b, then it is NOT a function (one element has two images).

4. Types of Functions

One-One (Injective)

f: A → B is one-one if no two elements of A have the same image.
i.e., f(a₁) = f(a₂) ⟹ a₁ = a₂.

Onto (Surjective)

f: A → B is onto if every element of B has at least one pre-image in A.
i.e., Range of f = Co-domain (B).

Bijection (One-One & Onto)

A function that is both one-one and onto. There is a perfect pairing between A and B.

Identity Function

f: A → A defined by f(x) = x for all x ∈ A. Every element maps to itself.

Constant Function

f: A → B defined by f(x) = k for all x ∈ A (k is a fixed constant). Range = {k}.

5. Composition of Functions

If f: A → B and g: B → C, then the composition g ∘ f : A → C is defined as (g ∘ f)(x) = g(f(x)).

Order matters: f ∘ g ≠ g ∘ f in general. Always evaluate the inner function first.
Example
f(x) = 2x + 1, g(x) = x²
(f ∘ g)(x) = f(g(x)) = f(x²) = 2x² + 1
(g ∘ f)(x) = g(f(x)) = g(2x+1) = (2x+1)²

6. Inverse of a Function

If f: A → B is a bijection, then there exists a function f⁻¹: B → A called the inverse of f, such that f⁻¹(f(x)) = x.

Only a bijective function has an inverse.

How to find the inverse:

  1. Replace f(x) with y.
  2. Express x in terms of y.
  3. Replace y with x to get f⁻¹(x).
  4. Verify: f⁻¹(f(x)) = x.
Example
f(x) = 3x + 2
y = 3x + 2 → x = (y − 2)/3
∴ f⁻¹(x) = (x − 2)/3
