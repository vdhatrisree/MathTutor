Cartesian Product & Relations

1If A = {1, 2, 3} and B = {4, 5}, find A × B and n(A × B).2 M
A × B = {(1,4),(1,5),(2,4),(2,5),(3,4),(3,5)}
n(A × B) = 3 × 2 = 6
2If n(A) = 4 and n(A × B) = 20, find n(B).1 M
n(A × B) = n(A) × n(B) → 20 = 4 × n(B)
∴ n(B) = 5
3Let A = {1,2,3,4,5}. A relation R is defined as R = {(x, y) | y = x + 1}. Find R, domain and range of R.3 M
R = {(1,2),(2,3),(3,4),(4,5)}
Domain = {1,2,3,4} (4 is not included as 5+1=6 ∉ A)
Range = {2,3,4,5}

Identifying Functions & Types

4Is R = {(1,a),(2,b),(1,c)} a function from A = {1,2} to B = {a,b,c}? Justify.2 M
NOT a function.
Element 1 maps to both 'a' and 'c'. In a function, each element of A must have exactly ONE image in B.
5Let f: {1,2,3} → {a,b,c,d} be defined by f = {(1,a),(2,b),(3,c)}. Is f one-one? Is f onto?2 M
One-One: YES — No two elements share the same image.
Onto: NO — Element 'd' ∈ B has no pre-image. Range = {a,b,c} ≠ Co-domain.
6Prove that f: R → R defined by f(x) = 2x + 3 is a bijection.4 M
Step 1 (One-One): Assume f(x₁) = f(x₂)
2x₁ + 3 = 2x₂ + 3 → x₁ = x₂. ✓ One-One.

Step 2 (Onto): For any y ∈ R, let x = (y−3)/2 ∈ R.
Then f(x) = 2·(y−3)/2 + 3 = y. ✓ Onto.

∴ f is a bijection.

Composition of Functions

7If f(x) = 2x + 1 and g(x) = x² − 3, find (f ∘ g)(2) and (g ∘ f)(2).3 M
(f ∘ g)(2) = f(g(2)) = f(4−3) = f(1) = 2(1)+1 = 3

(g ∘ f)(2) = g(f(2)) = g(5) = 25−3 = 22

Note: f∘g ≠ g∘f (3 ≠ 22)
8If f(x) = 3x + 5 and (f ∘ g)(x) = 6x + 5, find g(x).3 M
(f ∘ g)(x) = f(g(x)) = 3·g(x) + 5 = 6x + 5
3·g(x) = 6x → g(x) = 2x

Inverse Functions

9Find the inverse of f(x) = 5x − 3 and verify f⁻¹(f(x)) = x.3 M
Let y = 5x − 3 → x = (y + 3)/5
f⁻¹(x) = (x + 3)/5

Verification: f⁻¹(f(x)) = f⁻¹(5x−3) = (5x−3+3)/5 = 5x/5 = x ✓
10If f: R→R is defined by f(x) = (3x + 7)/5, find f⁻¹(4).3 M
y = (3x + 7)/5 → 5y = 3x + 7 → x = (5y − 7)/3
f⁻¹(x) = (5x − 7)/3
f⁻¹(4) = (20 − 7)/3 = 13/3
