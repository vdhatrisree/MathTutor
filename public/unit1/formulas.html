Chapter 1 — Key Formulas

All formulas needed for exams · Class 10 Samacheer Kalvi

Sets & Cartesian Product

Cartesian Product
A × B = {(a, b) | a ∈ A, b ∈ B}
Number of elements: n(A × B) = n(A) × n(B)
Relation
R ⊆ A × B
Any subset of A × B is a relation from A to B.

Domain, Co-domain & Range

Domain of a Relation / Function
Domain = {a | (a, b) ∈ R for some b ∈ B}
The set of all first elements (input values).
Range vs Co-domain
Range ⊆ Co-domain
Range = set of all actual output values.
Co-domain = set B (all possible outputs).

Function Composition

Composition: g ∘ f
(g ∘ f)(x) = g(f(x))
First apply f, then apply g to the result.
Domain of g∘f: x must be in domain of f, and f(x) must be in domain of g.
Composition: f ∘ g
(f ∘ g)(x) = f(g(x))
⚠ Generally: f ∘ g ≠ g ∘ f (composition is NOT commutative)
Composition with Identity
f ∘ I = I ∘ f = f
Composing any function with the identity function gives the same function.

Inverse Function

Inverse Function Definition
f⁻¹(f(x)) = x and f(f⁻¹(y)) = y
Exists only when f is a bijection (one-one and onto).
Inverse of a Linear Function f(x) = ax + b
f⁻¹(x) = (x − b) / a
Valid only when a ≠ 0.
Example: f(x) = 3x + 2 → f⁻¹(x) = (x − 2)/3
Inverse of Inverse
(f⁻¹)⁻¹ = f
The inverse of the inverse is the original function.

Types of Functions — Summary

One-One Test (Injective)
f(a₁) = f(a₂) ⟹ a₁ = a₂
No two different inputs have the same output.
Onto Test (Surjective)
Range of f = Co-domain B
Every element of B is the image of at least one element of A.
Bijection
One-One AND Onto ⟹ Bijection
Invertible Only a bijection has an inverse function.
