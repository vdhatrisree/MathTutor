Questions

1 Find the distance between the points A(2, 3) and B(6, 6). 2 marks
Solution:
Using the distance formula: d = √[(x₂−x₁)² + (y₂−y₁)²]
d = √[(6−2)² + (6−3)²]
d = √[4² + 3²]
d = √[16 + 9]
d = √25
d = 5 units
2 Find the midpoint of the line segment joining A(4, −2) and B(−2, 8). 2 marks
Solution:
Using the midpoint formula: M = ((x₁+x₂)/2, (y₁+y₂)/2)
M = ((4 + (−2))/2, (−2 + 8)/2)
M = (2/2, 6/2)
M = (1, 3)
3 Find the point which divides the line segment joining A(1, 3) and B(4, 9) internally in the ratio 1 : 2. 3 marks
Solution:
m = 1, n = 2, A = (1, 3), B = (4, 9)
Using Section Formula: P = ((mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n))
x = (1×4 + 2×1)/(1+2) = (4 + 2)/3 = 6/3 = 2
y = (1×9 + 2×3)/(1+2) = (9 + 6)/3 = 15/3 = 5
P = (2, 5)
4 Find the area of the triangle with vertices A(1, 2), B(3, 4), and C(5, 6). Are these points collinear? 3 marks
Solution:
Area = ½|x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|
= ½|1(4−6) + 3(6−2) + 5(2−4)|
= ½|1(−2) + 3(4) + 5(−2)|
= ½|−2 + 12 − 10|
= ½|0|
Area = 0

Since area = 0, the three points A(1,2), B(3,4), C(5,6) are collinear (they lie on the same straight line).
5 Find the slope of the line passing through the points A(2, 3) and B(5, 9). 2 marks
Solution:
Slope m = (y₂−y₁)/(x₂−x₁)
m = (9−3)/(5−2)
m = 6/3
m = 2
6 Find the equation of the line with slope 3 and passing through the point (1, 4). 3 marks
Solution:
Using point-slope form: y − y₁ = m(x − x₁)
y − 4 = 3(x − 1)
y − 4 = 3x − 3
y = 3x − 3 + 4
y = 3x + 1
7 Find the value of k if the points A(1, k), B(2, 3), and C(3, 1) are collinear. 4 marks
Solution:
For collinearity: x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂) = 0
1(3−1) + 2(1−k) + 3(k−3) = 0
1(2) + 2(1−k) + 3(k−3) = 0
2 + 2 − 2k + 3k − 9 = 0
4 − 9 − 2k + 3k = 0
−5 + k = 0
k = 5
8 Check whether the lines y = 2x + 1 and y = 2x − 3 are parallel, perpendicular, or neither. 2 marks
Solution:
Line 1: y = 2x + 1 → slope m₁ = 2
Line 2: y = 2x − 3 → slope m₂ = 2
Since m₁ = m₂ = 2, the lines have equal slopes.
Also, y-intercepts are different (1 ≠ −3), so the lines are distinct.
The lines are parallel.
9 Find the perpendicular distance from the point (3, 4) to the line 3x − 4y + 10 = 0. 4 marks
Solution:
Distance formula from point (x₁,y₁) to line ax + by + c = 0:
d = |ax₁ + by₁ + c| / √(a² + b²)

Here: a = 3, b = −4, c = 10, (x₁,y₁) = (3, 4)
d = |3(3) + (−4)(4) + 10| / √(3² + (−4)²)
d = |9 − 16 + 10| / √(9 + 16)
d = |3| / √25
d = 3/5
d = 3/5 = 0.6 units
10 Find the centroid of the triangle with vertices A(2, 4), B(6, 2), and C(4, 8). 3 marks
Solution:
Centroid formula: G = ((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)
G_x = (2 + 6 + 4)/3 = 12/3 = 4
G_y = (4 + 2 + 8)/3 = 14/3
G = (4, 14/3) ≈ (4, 4.67)
