Chapter 3 — Key Formulas

All formulas needed for exams · Class 10 Samacheer Kalvi

Polynomials

Remainder Theorem
Remainder = p(a) when p(x) ÷ (x − a)
Substitute x = a directly into the polynomial.
Factor Theorem
(x − a) is a factor of p(x) ⟺ p(a) = 0
If p(a) = 0, then (x − a) divides p(x) exactly.

Quadratic Equations

Quadratic Formula
x = [ −b ± √(b² − 4ac) ] / 2a
For ax² + bx + c = 0, a ≠ 0
Discriminant
Δ = b² − 4ac
Δ > 0: Two distinct real roots
Δ = 0: Equal (repeated) roots
Δ < 0: No real roots
Sum of Roots (Vieta's)
α + β = −b / a
Sum of both roots of ax² + bx + c = 0
Product of Roots (Vieta's)
αβ = c / a
Product of both roots of ax² + bx + c = 0
Forming Quadratic from Roots
x² − (α + β)x + αβ = 0
Given the roots α and β, this is the quadratic equation.

Matrices

Matrix Addition / Subtraction
(A ± B)ᵢⱼ = aᵢⱼ ± bᵢⱼ
Only possible if A and B have the same order.
Scalar Multiplication
(kA)ᵢⱼ = k · aᵢⱼ
Multiply every element of A by scalar k.
Matrix Multiplication
(AB)ᵢⱼ = Σₖ aᵢₖ · bₖⱼ
A must be m×n and B must be n×p. Result is m×p.
AB ≠ BA in general.
Identity Matrix Property
AI = IA = A
Multiplying by identity matrix gives the same matrix.

Simultaneous Equations (Cross Multiplication)

Cross Multiplication Rule
x/(b₁c₂−b₂c₁) = y/(c₁a₂−c₂a₁) = 1/(a₁b₂−a₂b₁)
For the system: a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0
