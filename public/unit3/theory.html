1. Polynomials

Polynomial

An expression of the form aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀, where aₙ ≠ 0 and n is a non-negative integer.

TypeDegreeExample
Constant07

Quadratic2x² − 5x + 6
Cubic3x³ − 2x² + x − 1
Remainder Theorem

When a polynomial p(x) is divided by (x − a), the remainder is p(a).

Factor Theorem

(x − a) is a factor of p(x) if and only if p(a) = 0.

Example
Is (x − 2) a factor of x³ − 6x² + 11x − 6?
p(2) = 8 − 24 + 22 − 6 = 0 ✓ Yes, it is a factor.

2. Simultaneous Linear Equations

Two equations in two unknowns. Solved by:

Elimination Method

Multiply equations to make coefficients of one variable equal, then add or subtract to eliminate it.

Substitution Method

Express one variable in terms of the other from one equation, substitute into the second.

Cross Multiplication

For a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0:

x/(b₁c₂ − b₂c₁) = y/(c₁a₂ − c₂a₁) = 1/(a₁b₂ − a₂b₁)

3. Matrices

Matrix

A rectangular arrangement of numbers in rows and columns. Order: m × n (m rows, n columns).

Types of Matrices

  • Row matrix: Only one row (1 × n)
  • Column matrix: Only one column (m × 1)
  • Square matrix: m = n (equal rows and columns)
  • Identity matrix (I): Square matrix with 1s on diagonal, 0s elsewhere
  • Zero matrix (O): All elements are 0

Matrix Operations

  • Addition/Subtraction: Only possible if matrices have the same order. Add/subtract corresponding elements.
  • Scalar Multiplication: Multiply every element by the scalar.
  • Matrix Multiplication AB: Possible only if columns of A = rows of B. Result order: (m×n)(n×p) = m×p.
AB ≠ BA in general. Matrix multiplication is NOT commutative.

4. Quadratic Equations

Standard Form

ax² + bx + c = 0, where a ≠ 0. The solutions are called roots.

Methods of Solving

  • Factorisation: Write ax²+bx+c = a(x−α)(x−β) and solve.
  • Completing the Square: Rewrite as (x + p)² = q form.
  • Quadratic Formula: x = [−b ± √(b²−4ac)] / 2a

Discriminant (Δ = b²−4ac)

DiscriminantNature of Roots
Δ > 0Two distinct real roots
Δ = 0Two equal real roots (repeated root)
Δ < 0No real roots (imaginary roots)
Vieta's Formulas (Sum & Product of Roots)

If α and β are roots of ax²+bx+c=0:
Sum: α + β = −b/a
Product: αβ = c/a
