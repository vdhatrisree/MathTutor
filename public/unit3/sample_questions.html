Remainder & Factor Theorems

1Find the remainder when p(x) = x³ − 2x² + 3 is divided by (x − 1).2 M
By the Remainder Theorem, remainder = p(1)
p(1) = (1)³ − 2(1)² + 3 = 1 − 2 + 3 = 2
The remainder is 2.
2Show that (x − 2) is a factor of p(x) = x³ − 6x² + 11x − 6.2 M
By the Factor Theorem, (x − 2) is a factor if p(2) = 0.
p(2) = (2)³ − 6(2)² + 11(2) − 6
p(2) = 8 − 24 + 22 − 6 = 0 ✓
Since p(2) = 0, (x − 2) is a factor of p(x).

Quadratic Equations

3Solve x² − 5x + 6 = 0 by factorisation.2 M
Find two numbers whose sum = −5 and product = 6 → (−2) and (−3)
x² − 5x + 6 = (x − 2)(x − 3) = 0
x − 2 = 0 or x − 3 = 0
x = 2 or x = 3
4Solve x² − 4x + 1 = 0 using the quadratic formula.3 M
a = 1, b = −4, c = 1
Discriminant Δ = (−4)² − 4(1)(1) = 16 − 4 = 12
x = [−(−4) ± √12] / 2(1)
x = [4 ± 2√3] / 2
x = 2 + √3 or x = 2 − √3
5Find the sum and product of roots of 2x² − 7x + 3 = 0.2 M
a = 2, b = −7, c = 3
Sum of roots: α + β = −b/a = −(−7)/2 = 7/2
Product of roots: αβ = c/a = 3/2 = 3/2
6Form a quadratic equation whose roots are 3 and −5.2 M
Sum of roots: α + β = 3 + (−5) = −2
Product of roots: αβ = 3 × (−5) = −15
Quadratic equation: x² − (α + β)x + αβ = 0
x² − (−2)x + (−15) = 0 → x² + 2x − 15 = 0
7Find the nature of roots of x² − 6x + 9 = 0.2 M
a = 1, b = −6, c = 9
Discriminant Δ = b² − 4ac = (−6)² − 4(1)(9) = 36 − 36 = 0
Since Δ = 0, the roots are real and equal.
x = −b/2a = 6/2 = 3 (repeated root)

Simultaneous Equations

Advanced Problems

9If α and β are roots of 3x² + 5x − 2 = 0, find α² + β².4 M
a = 3, b = 5, c = −2
α + β = −b/a = −5/3
αβ = c/a = −2/3
Using the identity: α² + β² = (α + β)² − 2αβ
α² + β² = (−5/3)² − 2(−2/3)
α² + β² = 25/9 + 4/3
α² + β² = 25/9 + 12/9 = 37/9
